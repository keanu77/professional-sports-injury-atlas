# Suggested labels

Prepared for manual maintainer review; this file does not create labels. Inspect existing repository labels before adding or renaming any. Preserve labels already used by issues or automations.

| Label              | Meaning                                                            | Suggested color |
| ------------------ | ------------------------------------------------------------------ | --------------- |
| `bug`              | Reproducible software defect                                       | `d73a4a`        |
| `enhancement`      | Agreed improvement to a user task                                  | `a2eeef`        |
| `documentation`    | Onboarding, explanation, translation, or links                     | `0075ca`        |
| `content/source`   | Sourced editorial correction, requiring content review             | `7057ff`        |
| `needs-triage`     | Scope or reproduction needs maintainer review                      | `ededed`        |
| `help wanted`      | Maintainer welcomes an external contribution                       | `008672`        |
| `good first issue` | Small, bounded task with clear files and a maintainer able to help | `7057ff`        |
| `accessibility`    | Keyboard, screen-reader, contrast, or motion behavior              | `1d76db`        |

Issue templates deliberately do not auto-assign labels that may be missing on forks. Label clinical changes for review; never label a submitted source as medically approved merely because an issue or PR exists. Security reports use the private channel in [SECURITY.md](../../SECURITY.md).
