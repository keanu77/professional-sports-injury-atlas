## 分類方案

1. **建議：依可見內容採多標籤。** 同片可在不同類型出現，各分類數量可能相加超過 200；全站及篩選結果按 slug 去重。能從受傷瞬間找到同時含解說／採訪的影片。
2. **替代：每支只指定主要類型。** 類別數量相加等於 200，但混合影片只能從其中一類找到。
3. **只增加現有四種片型的入口。** 工程較少，但會沿用 113 個未知值，也會漏掉新聞／訪談中的受傷片段，不建議作為本次最終成果。

## 建議類型與納入界線

| 類型 | 必須看到的內容 |
| --- | --- |
| 受傷瞬間 | 該事件的撞擊、跌落、扭轉或其他受傷過程；看不到組織受損不妨礙分類，但不能從影像推定診斷。一般比賽素材不算。 |
| 傷後反應／退場 | 同事件當場不適、倒地後處理、協助離場、抬離或醫療暫停；單獨不視為受傷瞬間。 |
| 事後採訪／本人說明 | 受傷選手、教練、隊友、對手或醫療團隊談該事件；包含本人影片日誌與旁白。紀錄說話者角色，不能將對手談話誤標為傷者本人，也不能把本人日誌稱為記者採訪。 |
| 新聞報導 | 主播／記者整理該事件的消息、公告或後續。只有既有新聞來源連結不算影片內容。 |
| 專業解說 | 影片實際分析動作、解剖、傷害機制或處理原則；另記解說者身分，不以此推定個案臨床確診。 |
| 復健／回場紀錄 | 實際復健、恢復訓練或傷後復出紀錄。採訪中只提到復健，不自動增加本標籤。 |
| 紀錄片／事件回顧 | 有組織地回顧同一事件與歷程的紀錄片、專題或回顧影片，允許與其實際包含的其他內容標籤共存。 |
| 賽事紀錄／觀賽評論 | 保留比賽動作、較長賽事或觀賽反應；本標籤本身不表示已看見受傷瞬間。用於 Andrade 完整地板動作、UFC Full Blast 觀賽評論等無法硬套醫療解說的內容。 |

後續逐片分析補入第八類，並將本人影片日誌與採訪的命名界線寫清楚；使用者已同意照草案實作。一般轉播主播的即時敘述不自動列為新聞報導或專業解說。賽事片段若含已確認傷害動作，可以同時有受傷瞬間標籤；無法確認最初受傷動作時，不能用這個一般類型掩蓋待查事項。

## 逐片分析與證據

- 建立完整 200 列清單，將 slug、精確原片 URL／ID、現有播放起點及時長與既有核准內容綁定。
- 利用可追溯的既有實看紀錄；證據不足或主要片型缺值時補看原片。每個內容標籤記錄可見內容與時間位置、查核日期、依據／限制。既有播放成功、HTTP 200、片名或縮圖不能替代內容分析。
- 長影片明確記錄看過的事件段落；不把短暫抽查描述成全片逐秒檢視。未證實的次要內容不加入標籤。
- 若影片無法查看，保留實際阻擋與未確認狀態並繼續處理其他影片。不能用猜測填滿 200；全部 200 列的分析完成與否須在最終報告如實說明。
- 不改寫既有選片／臨床核准欄位。使用獨立內容分類資料，對精確 URL 及事件綁定；影片替換時原分類證據失效。

## 首頁與瀏覽行為

- 首頁既有部位、運動、情境分類旁加入「依影片類型」，每類顯示符合的不同影片數量。
- 各類入口提供可分享的分類頁；首頁影片列表另提供類型篩選，與姓名／關鍵字搜尋及全部／精選／熱門範圍相容。
- 同片多標籤仍只在目前列表顯示一次。卡片顯示已確認類型；詳細頁可見分類及已觀察片段的起點，影片仍在使用者同意後才連線載入。
- 手機按鈕可換行、鍵盤可操作，狀態與篩選結果數可由輔助工具讀取。關閉 JavaScript 時分類連結及全部影片仍可閱讀。
- 首頁說明文字涵蓋受傷片段、採訪、解說與復健，避免把 200 支全部描述成受傷瞬間。

## 驗收與發布

- 資料：200 個唯一事件全覆蓋，精確影片綁定，每類至少一個有證據的內容標籤；類別計數與實際篩選一致，舊病例及核准不變。
