主要受眾：醫療教學；兼顧一般民眾。此定位已由使用者確認。  
本輪交付：重新盤點、獨立複核與執行計畫；未修改產品、發布網站或核發醫學內容審閱。

## 1. 結論與驗收範圍

網站已具備可延續的基礎：200 支影片、30 種運動、14 個部位，已有多條件搜尋、片型分類、點擊後載入、來源與限制說明、回場時間軸、醫學內容及發布檢查。優先工作是讓每支影片都能清楚回答「看哪一段、能學到什麼、哪些敘述有證據、資訊查到哪一天」，並讓這些品質持續可驗證。

100 分定義為下列六個面向、全部硬性條件，在**指定版本、日期與測試範圍**通過。它是站方品質驗收標準，不是外部認證，也不代表第三方影片永久可播。每次發布需重新產生證據；網站持續營運時另依週期追蹤。

**驗收分母採該版本全部公開有效影片 N，目前基線為 200。** 本文的 200 支是本輪盤點基線；執行時新增 Curry 或其他影片，必須同步擴大驗收範圍與所有清單，不得只驗原始 200 支。報告同時列出基線、增加、替換、封存及最終 N，避免改變分母掩蓋未完成項目。

目前不給一個憑印象的總分：全量資料已盤點，但本輪沒有逐支重播 200 支影片、逐頁重讀全部來源，亦未完成手機、讀屏及真實訪客效能量測。這些應標記「待驗」，不能當作滿分或直接判為失敗。

完整範圍分為：

- **全部公開內容**：200 筆影片基本教學資料、重要診斷／回場主張、來源、媒體可及性、授權用途、可播放性及替代入口。
- **深入教學內容**：先建立 20 筆旗艦案例，提供完整觀察任務、分段、比較案例與自我檢核；其餘影片仍須具備基本教學摘要。
- **網站能力**：公開首頁、分類頁、兩種詳情模板、投稿頁、錯誤與無 JavaScript 狀態；涵蓋桌機、手機、鍵盤及讀屏。
- **營運能力**：版本對照、內容責任、複查排程、來源與播放監控、發布及回復程序。

### 不可由其他分數抵銷的條件

1. 不得有已確認而未處理的重大醫學錯誤、張冠李戴影片或把推論寫成確診；不得把職業球員回場天數當成個人復健期限。
2. 每筆重要診斷及回場結論必須有支持來源，未知明示；沒有精確日就不補造日期，不以「兩週後再評估」充當復出日。
3. 目前已確認不能播放的影片不得繼續以「可播放」呈現；須有可用替代或明確停用／封存狀態與學習替代。未能判定的第三方狀態不當作失效，也不算已證實可用。
4. 需要字幕或口述影像的媒體，必須符合適用條件；簡短摘要不能自動取代字幕或完整必要資訊。第三方控制限制須誠實揭露，未完成前不能宣稱全站 AA 或 100 分。
5. 發布核可、實播證據、產物 digest 與線上版本須對應同一批內容；不得補改歷史核准或降低門檻來取得通過。

封存須經編輯核定、移出有效教學／可播放目錄並更新分母，公開保留來源、更正及封存原因；封存頁本身仍需通過適用的網站可及性驗收。若仍嵌入影片或作主要教材，字幕、必要資訊與實播門檻仍適用，不能只加封存標籤取得滿分。

## 6. 每支影片的完成定義

### 驗收版本全部 N 支的最低教學單位

1. 正確運動員、事件 ID、傷害部位／事件日期精度及影片來源；同一人不同次受傷分開。
2. 影片類型與用途：受傷畫面、傷後反應、訪談、專業分析、新聞、紀錄片或復健／回場，可複選。
3. 「本段要看什麼」與開始／結束時間，至少一個可觀察重點；若影片無法呈現受傷瞬間，直接說明。
4. 分開呈現可見畫面、公開報導診斷、一般醫學解釋與仍未知的內容；每個重要主張能找到對應來源。
5. 字幕／必要視覺敘述的實際狀態、語言與替代學習方式；來源使用方式符合現行政策。
6. 已知後續與回場里程碑、資訊截至日期、複查責任及下一次期限。
7. 最近播放證據與失效時的處理方式；區分本站嵌入、原平台開啟及受地區／登入限制。

### 20 支旗艦的加值教材

每頁 1–3 個學習目標、觀看前問題、2–4 個觀察提示、帶理由的 2–3 題檢核，以及一組相似／相異比較案例。一般民眾先看到簡明重點與適當求助資訊；醫療讀者可展開機轉、證據限制與參考資料。沿用已有專業筆記與安全提示，不把每頁塞成同樣長的課本。

第一批建議以既有七個 core 中的阿基里斯腱與踝傷、Watkins 膝傷、Brees 肋傷、神經症狀案例及一筆合格 Curry 案例組成試作候選。最終 20 筆須依影片可及性、觀察清晰度、證據及教學覆蓋決定，不預設知名度最高就是最佳教材。

研究更新採共用主題單元：例如韌帶傷害、肌腱傷害、腦震盪、軀幹傷害與神經症狀。現有只有 3 筆獨立研究段落不等於其餘 197 筆都要另寫論文；引用應回答實際教學問題，由醫療審閱者確認適用範圍。

## 9. 使用者與工程驗收

### 必做的使用任務

1. 用「柯比」與「Kobe」找到同一已收錄事件；用「Curry」知道已收錄及尚未收錄的真實狀態。
2. 找到近兩年指定部位的影片，分享 URL 後仍保留相同篩選；日期未知不被默默排成某一天。
3. 在長訪談 30 秒內找到應觀看的核心段落，並能指出觀察任務。
4. 只看摘要也能分辨報導診斷、畫面觀察與一般醫學推論。
5. 讀到回場天數時能說出對應里程碑，且理解不是自己的復健期限。
6. 關閉聲音或使用讀屏時仍取得必要教學資訊；影片未載入、失敗或不能嵌入時有可理解替代。
7. 僅用鍵盤完成搜尋、篩選、詳情與返回；320 CSS px、200% 縮放下內容不被遮擋。
8. 輸入錯誤來源網址時知道哪一欄有問題；驗證失敗後可復原內容，無真實外寄。
9. 找到一個結論的來源及資訊截至日期，並可提出資料修正。

建議至少 12 名受測者：4 名醫師／治療師、4 名學生、4 名一般民眾。預先定義任務成功條件；主要任務完成率目標 ≥90%，重大誤讀須全部修正。這是小樣本可用性驗收，不宣稱學習成效或臨床效益的統計證明。失敗任務修改後再測，不以滿意度問卷取代實際操作。

### 測試及發布證據

- 沿用既有 `plan:verify`、`check`、`content:check`、`test:unit`、`build:review`、`brand:verify`、`verify:review-artifact`；新增重要契約與迴歸情境，不為單純文字修改堆疊測試。
- 將 `test:e2e` 與 `test:lighthouse` 接到明確的公開模式產物。現有預設 review build 及 skip 結果不可作公開 200 筆的通過證明。
- 代表路徑至少包含首頁、分類、core、observation、長訪談、MLB、投稿及錯誤狀態；Chrome／Safari／Firefox，行動 Safari／Chrome，鍵盤與 VoiceOver。
- 效能先做公開產物的多次 mobile lab 基準，保存測試環境與變異；正式訪客資料按現行隱私／DNT／GPC 政策最小化蒐集。流量不足時明示樣本不足，不虛報 CWV 通過。
- `release:public` 的 clean-tree、核可、digest、來源及實播門檻保持有效；修改內容之後重新建立對應證據。
- 發布後另驗 `/version.json`、內容文字、播放器實況、錯誤替代、資源／canonical，以及可回復的前一版本。API 接受不等於信件已收到，mock 不等於真播放。
