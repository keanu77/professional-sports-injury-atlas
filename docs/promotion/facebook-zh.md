準備運動醫學課程時，找到一段影片之後，往往還要再查事件背景、原始報導，以及後續回場資訊。我把這些查找步驟整理成「運動傷害影片圖鑑」，讓醫療同仁、治療師與教育工作者備課時，有個追查來源的入口。

目前圖鑑整理了 200 支影片，涵蓋 30 種運動與 14 個部位。可以搜尋選手，依運動、部位與影片類型篩選，再從事件頁回到原始來源。其中有 7 個核心案例、193 個觀察頁，資料深度與審閱流程不同，不能視為 200 份同等級的臨床案例。

影片可以協助觀察動作、提出討論問題；單靠影片，無法確診，也不能替某個人決定治療或回場時間。教學使用仍需要結合完整資訊，並遵守原平台與素材的使用條件。

這次也整理了開源專案的參與方式。想改善文件、無障礙介面或回報來源問題，都能從 GitHub 開始。自有程式碼與適用開發文件採 MIT；醫療編輯資料、影片與圖片另有權利範圍。想做自己的索引，也可以先試試純虛構的示範內容。

歡迎提供有來源的修正建議；工具有幫助的話，也可以給一顆 Star，方便下次找到。
