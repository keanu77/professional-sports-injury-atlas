# 首頁與影片目錄 UI/UX 完成紀錄

依使用者「社群追蹤入口一樣在前面，其他依你的建議去修改」完成並部署。正式站：https://injury.sportsmedicine.tw/ 。網站來源 `9a4810b4e832d98d5411532c8f7698281370ea15`；部署 https://4d4f7271.sports-injury-atlas.pages.dev 。後續收尾提交僅含文件。

## 已完成的調整

- 社群追蹤入口維持在最前面；縮短介紹，搜尋移至分類導覽前。390px 實測搜尋框由先前稽核約第 1,452px 提前至 671px，社群入口在 127px，頁面無水平溢出。
- 手機分類按鈕改為 2×2；分類面板預設收合，點選才展開，深層連結會開啟對應面板。無 JavaScript 時仍保留全部分類連結。
- 關鍵字、影片類型、運動與部位可交叉篩選；首頁及 8 個類型頁共用控制介面。類型頁固定所屬類型，首頁另保留全部／精選／熱門範圍。
- 首批 24 支，每次載入更多增加 24 支；先篩選完整 200 支再分批呈現，顯示符合數與已載入數，提供返回搜尋入口。無 JavaScript 仍可取得全部靜態卡片。
- `q`、`type`、`sport`、`body`、`mode` 存入網址，可複製分享並支援瀏覽器上一頁／下一頁。
- 卡片以選手姓名為標題開頭，統一字體、提高標籤與次要文字可讀性，觸控標籤至少 44px。影片 CTA 已改為真正連結。
- 明示同片可屬多類、各類數量不宜相加；替代類型導覽可展開。「關鍵片段」改為「預設播放起點」，片段連結標明 YouTube 與另開分頁。
