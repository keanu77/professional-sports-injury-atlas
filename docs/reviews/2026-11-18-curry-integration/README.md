## 審核範圍與證據

[event-content-approval.json](event-content-approval.json) 保存使用者原句、原三事件內容及雜湊。這是實際使用者確認，沒有替使用者虛構姓名、資格或其他教材的審閱簽章。

[metadata.json](metadata.json) 是本輪 YouTube oEmbed 的標題、發布者及原始封面資料。[media.json](media.json) 保存原生 Chrome 的部分播放進度、片長、英文自動字幕選單及限制：三支皆有原平台播放證據，但這些不是完整內容／字幕準確性或 owned HTTPS 嵌入證據。腹部影片截圖的影片區沒有可辨識動作，因此沒有新增受傷動作描述。影片均已暫停；使用者切換 Chrome 視窗後停止 UI 操作。

歷史研究檔保留原始查核嘗試，新增本輪收錄與審閱狀態。`includedInPublicCatalog=true` 指候選分支的目錄，`productionDeployed=false` 明確區分尚未正式部署。
