## 每片分三個不同階段

1. **原片視聽**：確認事件、傷者身份、原始發布者、實際內容、片長與合適時間碼。這一步完成才能補 production schema 所需值；不能用 oEmbed、標題、他人時間碼或搜尋摘要代替。
2. **案例資料及候選成品**：完成來源／臨床／分類審查，依既有契約建立單一事件頁並測試搜尋、部位、運動分類與延遲載入。維持同意後嵌入。神經相關內容沿用已核准的「依受傷部位看影片 → 神經損傷」入口；不為本批建立額外神經專區。
3. **本站 HTTPS 實播及發布**：在合適的自有 HTTPS 候選成品，實際確認嵌入可播及有效時間窗，再走正常核准、輸入雜湊及發布檢查。原站可播不等於本站可嵌入；review-mode dist 不能公開上傳。

任何階段遇到地區限制、撤片、非原創轉載或事件不匹配，回到替代片搜尋，留下失敗紀錄。不得先計入首頁數字。來源或播放器核准未完成前，不以「可合法嵌入」形容候選。
