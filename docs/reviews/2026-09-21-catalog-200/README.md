查核日：2026-09-21。使用者已授權「如果覺得可行的話就做吧」，並明確核准本提案：「核准，照此實作（建議）」。本文件是已核准的編輯／呈現設計，不是逐片發布核准或醫學審查簽核。保留目前分支與既有內容，既有王建民案例保留。

## 結論及計數

擴至 200 個可區分的傷害事件具編輯與技術可行性；尚未找到並驗收 42 支可發布的新影片，故不是已完成的承諾。計數單位為事件頁，同一事件的不同剪輯不重複湊數。公開報導觀察頁不等於完整臨床確診病例。

- 正式站：154 頁，包含 7 個核心案例與 147 個觀察頁；17 種運動、11 個部位分類。
- 本機：158 頁。差額為 Jaylon Smith、Zack Kelly、Ryan Crouser、Rob Horne 四例，尚未上線。
- 保留既有頁面時：154 + 4 待發布 + 42 新增 = 200。
- 若另獲指示移除既有王建民案例：153 + 4 + 43 = 200。此次不擅自移除。未對全站所有來源國別完成查核，不宣称王建民是唯一需要檢查的台灣相關內容。
- 未發現完全相同影片網址或完全相同姓名／日期的重複，但缺日期、姓名異體及跨多場傷勢仍須人工核對。

## 資料品質優先事項

1. 正式站 113/154 頁沒有明確 footageKind。本機 observationFootageLabel 將未填值顯示為「受傷動作觀察」；這不證明 113 支全有受傷瞬間。新增片必填類型；既有缺值使用中性標籤，逐片查核後才改成受傷瞬間。
2. 新增病例須分開運動、部位、來源報導的傷害類型及證據確定性。不得從慢動作影像推定韌帶分級、神經損傷程度或回場日。
3. 頻道名稱或 oEmbed 回應成功不是完整權利查核，也不是實際嵌入播放成功。優先官方賽會、球隊、轉播權人、選手本人及原始採訪。
4. 目前 HTML 與目錄盤點涵蓋全站；本次沒有重看 154 支影片，也沒有逐例重新核定全部醫學來源。

## 三種方案

- 建議：缺口導向、沿用觀察頁，分三批約 14 例。改善多樣性，逐例驗收，改動限於資料、分類與必要的搜尋整合。
- 可選：先只增奧運／亞運案例。主題一致，但容易受版權、地域及嵌入限制影響，也補不齊過度使用傷害。
- 不建議：只挑容易找到的熱門聯賽片迅速補數。會持續偏重膝傷與三大球，降低新增 42 例的教學價值。

## 納入與發布設計

1. 新增內容排除台灣選手與台灣來源；不設年份下限。運動員訓練傷可納入但明標訓練情境；生活意外不能當成該運動的受傷機轉。
2. 一事件一頁。沿用目前觀察頁、來源引用、時間軸、延遲載入及同意後嵌入；不改七個核心案例的臨床核准契約。
3. 影片順序：受傷瞬間 → 本人談傷勢 → 原始新聞／專業說明。不同類型清楚標示；復賽不等於組織癒合。
4. 候選研究記錄留在 docs/reviews，不讓未驗收列入首頁總數。新運動只有首例合格時才加入 SPORTS 與 guidance；不產生空分類。
5. 每例記錄事件識別、影片來源、來源地查核、傷勢依據、日期確定性、片型、實際時長／片段位置及嵌入結果。未知值明標未知，不填假時長或假日期。
6. 本機資料／分類／搜尋／無障礙測試通過後，才準備候選成品。正式發布仍要求既有來源與核准契約、輸入雜湊及七日內自有 HTTPS 網域實際播放證據，不能以 HTTP 200 或測試替身取代。
7. 分三批約 14 例；每批記錄實際合格、待查、退件數。若合格數不足，先公布真實數量，不硬湊 200。

## 工程範圍

預計沿用 `src/data/videos/*` 的批次與事件檔，串接 `expansion.ts`、`event-updates.ts`、`sports.ts`、`observation-guidance.ts`、`public-video-ids.ts` 及對應發布證據。新增病例測試涵蓋唯一事件、非台灣来源審查紀錄、片型必填、可信來源、分類、搜尋與延遲嵌入。這份提案不改寫受控 authority ledger，也不替代後續詳細實作計畫。

使用者已核准設計，進入實作。實際進度、驗證與發布界線另記於本目錄的 implementation-status.md，不以候選清單數量冒充已新增影片數。
