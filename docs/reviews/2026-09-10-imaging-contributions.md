# 影像課程投稿整合

使用者要求七個影像教學站提供影片與文獻連結投稿。沿用此站既有匿名表單、安全驗證、同源 API、D1 配額與通知管道。新增 reference 類型，至少要求一個公開連結；contextUrl 僅認可明確列出的影像課程主機，清除無關 query，保留單元 hash。

76 項投稿與配額測試通過，包含文獻連結、未知來源阻擋、分類與訊息格式。型別檢查 0 errors/0 warnings。桌機與手機 30 項瀏覽器回歸測試全部通過（包括兩種主題、放大文字、可及性、資料保留及文獻投稿）。全程不寄出測試信。

本次變更範圍僅限投稿 UI、來源驗證、既有 API 接受新類型和測試；src/data/public-launch.v1.json 只重新計算實際 inputTreeDigest，不改審閱內容、審閱時間或任何醫療批准。
