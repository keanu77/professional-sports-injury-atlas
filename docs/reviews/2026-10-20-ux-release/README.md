# 2026-10-20 UX 發布驗證

使用者明確授權「請部署」及「允許，使用 Playwright 完成驗證與部署」。

本目錄保存本輪發布前的真實證據：200 支實際影片時間推進、5 支必要字幕開啟、完整型別／單元測試、桌面與手機互動檢查，以及最終來源清單。臨床、來源、權利與七日播放門檻維持原樣。

- `verification.json`：查核摘要與限制。
- `playback.all.json`：200 支真實播放結果，包含失敗後重新驗證成功的結果；原始嘗試與截圖保留在忽略提交的 `output/deploy-20261020/`。
- `source-manifest.json`：最終程式／測試 SHA-256。
- `refresh-playback.mjs`、`playback-refresh-manifest.json`：本輪固定 200 支的重現腳本與清單；不是未來新增影片的自動選取器。影片請求未替換；僅攔截觀看統計 POST，避免污染數據。

YouTube Shorts 的控制項會因工作階段不同而變化；字幕證據保留實際可見的「字幕/CC 已開啟」標籤。MLB 使用原始 Streamable 嵌入的播放按鈕。沒有改寫時間、暫停或就緒狀態。
