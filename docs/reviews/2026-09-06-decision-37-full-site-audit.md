# Decision 37：全站多模型稽核與優化建議

日期：2026-09-06（台灣時間）。範圍：<https://injury.sportsmedicine.tw/>，本機基準 `f6530d7b7f1d6e828aae82183843edbdfc8f6462`；僅審查，未修改網站程式、部署、寄信或寫入正式播放統計。

**目前網站的優勢是速度、來源透明與隱私設計；最有價值的下一步，是讓民眾更快選到影片、正確理解回場里程碑，並加強投稿與熱門排行的可靠性。這次未確認必須立即停站的 P0 問題。** 這不是完整滲透測試或醫療內容重新簽核。

## 模型參與與審查邊界

| 模型／方式 | 實際材料與分工 | 結果 |
|---|---|---|
| Codex CLI，指定 GPT-5.5 | 公開頁面文字；操作、可及性候選問題 | 有完整輸出；24.7 秒 |
| Grok CLI，CLI 顯示預設 grok-4.6 | 公開頁面文字；產品、分類、選片與下一步 | 有完整輸出；262.7 秒 |
| agy，指定 Gemini 3.1 Pro High | 公開頁面文字；醫學教育透明度與內容層次 | 有完整輸出；106.7 秒 |
| 本機 Qwen3.8 27B MLX | 完整提供的內容資料；另一次讀投稿、限流、播放與主站寄信依賴程式 | 兩次皆完成；输入分別 53,503／12,118 tokens，首尾哨兵均保留 |
| 主代理＋獨立 Pass 2 | 實際程式、正式站 DOM、鍵盤、Axe、Lighthouse、離線 API 模擬、套件公告 | 逐項複核模型原項，數字以實測為準；不採未證實漏洞 |

最初整包私有程式碼交由外部 CLI 的操作，被自動核准審查以第三方原始碼傳輸授權不足拒絕。後續獲准改為**只將已公開頁面文字交給外部模型**；私有程式碼由本機 Qwen 與本機程式檢查處理。沒有更改任何模型的權限設定。

外部文字擷取不等同 DOM 審查，會漏掉收合內容、動態狀態，也可能包含被隱藏的 honeypot。因此模型初稿均非最後結論。完整逐項裁定見 [Pass 2](evidence/decision-37/pass2.md)；39 個模型原項含重複建議、待驗項目及誤報，不能當作 39 個真實缺陷。

## 實測基準

- 本機 145 個 HTML 與正式網站 **145／145 SHA-256 相符**。包含 7 個完整個案頁、94 個動作觀察頁；101 支都有對應傷勢後續資料，94 支觀察資料與事件資料的回場日期沒有欄位衝突。10 筆未核定首次回場日期，保留空值與說明，沒有硬算天數。
- 現有分類為 **11 個部位、15 種運動、7 種情境**，棒球 **30 支**。精選實際 **6 支**，涵蓋棒球、網球、羽球、橄欖球與滑雪。全部清單前 7 張 NBA 卡不是精選或熱門榜。
- 首頁行動版 Lighthouse 13.4.1 單次實驗室測試：**效能 99、無障礙 98、最佳實務 96、SEO 100**；LCP 約 **1.72 秒**、TBT **0ms**、CLS **0.0012**。這不是所有訪客的 Core Web Vitals 實地統計。
- 390×844、預設字級：固定頁首 **177px**，影片清單起點約 **2,230px**，頁面總高約 **40,020px**。320px 寬且本站字級 150% 時，頁首约 **392px**、清單起點約 **5,430px**。
- 320／390／1440px、字級 100%／150% 的首頁量測沒有水平溢出；受測 Tab 序列沒有完全被頁首遮住的焦點。不能把頁首太高直接宣稱成已證實的 WCAG reflow 或焦點遮擋違規。
- 7 個個案頁的原始影片來源連結均出現 Axe WCAG 2.2 AA `target-size` 問題。代表頁連結約 **236.7×16px**，鄰近安全間距不足；首頁另有標題跳級最佳實務提醒。
- 145 頁內部連結目標檢查沒有找到缺失檔案；145 頁沒有 `og:image`，101 影片頁沒有 `VideoObject`，`/favicon.ico` 正式站為 404，建置產物沒有 sitemap。Lighthouse SEO 100 並不代表這些分享與索引功能已具備。

本輪沒有重新播放全部 101 支影片，也沒有重新逐篇查核所有選手病史原文。可播放狀態沿用既有審查證據，不宣稱本輪再次證明全部可播放；本輪完成全量結構／資料一致性、頁面同版核對、代表頁操作與已標記問題複核。

## 不採納的主要模型建議

- **查核日期不存在**：實際位於可展開來源中；已在正式頁展開驗證。可討論更醒目，但沒有違反目前「可展開查看」承諾。
- **精選都是 NBA**：實際是 6 支跨運動精選。模型誤把全部清單前 7 張當熱門／精選。
- **防垃圾「網站」欄位暴露、修正模式沒有必填頁面**：前者 `aria-hidden`、`tabindex=-1` 且裁切；後者切換後會改標籤、必填並預填目前頁面。正式 DOM 已複驗。
- **必須移除所有診斷名稱或更換 `/cases/` 網址**：報導已確認的診斷可以清楚歸屬來源；沒有必要因此改現有 URL。
- **郵件換行注入／投稿 URL SSRF／參考來源 XSS／任意 reply-to 漏洞**：模型沒有成立的利用路徑。投稿網址只寄為文字、HTML 經跳脫、主站訪客回覆地址是原功能，atlas 使用固定 no-reply。
- **相同 UUID 並發重複計數**：主鍵與 `INSERT OR IGNORE` 已去重；真正應處理的是程式化生成新 UUID。
- **修改 Klay Thompson 左右側、聲稱季前賽風險一定遠低於正式賽**：模型改寫引入錯誤或未經本輪查證的醫療推論，不採用。
- **兩支匿名球友影片仍公開**：它們只留在歷史原始資料，公開 loader 已排除。
- **NHS ACL 英文標題拼字是本站誤植且列 P1**：來源網站本身就是該標題，不能擅改凍結引文。可另提供易讀的來源譯名，不把來源原題當作緊急網站缺陷。

## 建議分批實作與驗收

1. **第一批，快速改善選片與可靠性**：01、02、04、05、06、07、08。驗收窄手機／大字、所有卡片必要欄位、里程碑與來源一致、空投稿拒絕、共享限流與同事件重送、修補依賴後建置。熱門功能的防濫用測試限離線／獨立 preview，不寫正式榜單。
2. **第二批，內容深度與分享**：03 先做現有 6 支精選的民眾導讀試點，再擴充；搭配 09、10、11、13。每篇相關文章先核對內容相關與正式網址，新增醫療文字仍須相應審查，不因多模型同意就當作醫師簽核。
3. **第三批，長期維護**：12、14、15。完成逐筆日期、外部來源與嵌入健康檢查、主站驗證邊界、通知營運驗收。是否涵蓋新增主站程式與實際測試寄信，需在實作範圍中明確列出。

本輪僅交付以上可審閱建議。既有版型、醫療資料、配額、影片、網域與正式網站均未修改。

## 熱門統計更新頻率
