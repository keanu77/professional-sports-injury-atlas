# 其餘 100 個個案的摘要擴充可行性

這份文件保留擴寫前的盤點快照。後續已完成第一批 10 例的本機摘要與共用模板，最新結果見[第一批實作紀錄](../2026-09-12-first10-expansion/README.md)；其餘 90 例仍待續作。

結論：100 頁都適合整理為「受傷當下、機轉解說、後續發展、來源」的閱讀架構。能寫多深入，要由各頁證據決定；目前不能認定 100 頁都能提供 Tatum 等級的動作分析或完整復健時間軸。

本輪逐筆閱讀 100 筆現有觀察、傷勢、後續摘要、背景與來源清單，並抽查部分外部來源。這是擴充可行性分析，沒有改寫或部署其餘 100 頁，也沒有重新播放全部影片、核讀全部來源正文，或新增臨床簽核。

## 建議依個案採用的寫法

| 情況                           | 建議寫法                                                   | 代表個案與注意事項                                                                             |
| ------------------------------ | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |

| 碰撞、摔落、骨折或複合外傷     | 說清接觸位置及事件順序，著重診斷、處置與功能恢復           | Paul George、Hayward、McDavid 等，不推算影片沒有量測的撞擊力或骨折細節                         |
| 頭頸部與顏面傷害               | 先區分公開診斷，再整理急性處置、恢復與回場                 | Crosby、Shoemaker、Dupont 等；不能從球員短期回場推導一般人的回場期限                           |
| 組織診斷或動作不清楚           | 以可見經過與已確認更新為主，縮短或省略組織受力推論         | Ronaldo、Salah、Julie Foucher、Oxlade-Chamberlain、Ibrahimovic、Pedroia 各有不同資訊限制       |

最容易寫錯的地方已記入逐案工作表：Klay 的兩次傷害、Kyrie 缺賽中的非傷勢因素、Simons 復出同場再傷、大谷先帶傷打擊後手術、棒球復健賽與大聯盟的差別，以及王建民 2008 足傷與後續肩傷的事件邊界。

## 技術可沿用，但不能直接批次填字

1. Tatum 的 `mechanism` 與 `timeline` 已置於共用事件資料結構，`EventFollowUp` 也被 94 個 video 頁共用。時間軸可沿用；video 路由尚未接入 `EventMechanism`。
2. 「從手術到重返賽場」「起步時的受力順序」是目前 Tatum 版的文字。擴充前應改成依個案調整或中性標題，避免替未手術、非起步、退役個案製造事實。
3. 目前 timeline 要求完整日期；Julie 等只能核實年／月的紀錄，需要日期精度或顯示文字欄位。不能為了通過欄位驗證捏造日期。已知後續出賽可加為里程碑，但不能回填成未核清的首次回場日。
4. 研究段落應允許省略。先辨明個案的動作，才選文獻；若僅有通用研究，必須明示不屬於該選手的測量或致傷因果。
5. 沿用既有來源與醫療簽核邊界，新增摘要不繼承舊醫療簽核。新內容完成後才做來源、日期、版面與公開建置的檢查。

## 建議處理順序

先做 10 個代表案例：Durant、Kobe、Rose、Jamal Murray、Beth Mead、Aaron Rodgers、Zverev、Paul George、Crosby、王建民。這組涵蓋不同運動、機轉、處置與回場層級，用來確認模板能容納差異。

之後處理其他 80 個已有回場日期的個案；另設 10 個首次回場未確認／不適用的工作清單。這是編輯工作順序，不是 90 頁可直接發布、10 頁不能做的分級。

每頁先完成事件與診斷核對，再寫機轉，接著補可證明的治療／訓練／賽事里程碑。主文建議約 400–700 字、時間軸約 3–7 個節點，依證據增減；不以相同篇幅或節點數作為驗收條件。沒有三個已完成個案的實作成本樣本，暫不提供整批工時或 token 的精確估計。
