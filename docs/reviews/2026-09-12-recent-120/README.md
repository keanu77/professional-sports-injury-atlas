# 近期個案擴充至 120 例

使用者指示：「再請你搜尋近3年個案，看能否增加到120個個案」、「我們先做120個個案後再來審查」。

事件窗口為 2023-09-12 至 2026-09-12；從 24 個候選選入 19 個不同事件。網站由 7 個原有臨床個案頁與 94 個觀察個案頁，擴充為 7 + 113 = 120 頁。新增項目均為附來源的公開報導與教學觀察，未新增個別臨床簽核。

每頁包含三步驟機轉摘要、一般受力說明、證據限制、傷勢與後續時間軸。診斷依球團、聯盟、協會或選手原始資料；影片只支持可見動作，不用來推定手術細節。

機轉影片以整段抽幀與相關序列核對：Ter Stegen 改用 Movistar Plus 動作重播；Musiala 改用可見爭球片段；Djokovic 的 Tennis Channel 影片以照片和新聞為主，分類為畫面未明且在頁面明示限制。影片檔只在本機暫存，網站保留原生 YouTube 嵌入及標準封面。

Porziņģis 6/17 術前帶傷出賽與 11/25 術後回場分開；Burrow 以季前賽為第一個比賽里程碑；Marín 列出 2026/3/26 退役；Hutchinson 訓練許可與正式回場分開。

## 稽核與發布順序

先完成 120 頁，再做完整多模型稽核與主 agent 對抗驗證，修正後才部署。使用者已明確同意本次隔離稽核副本交給 Codex、Grok、agy 外部模型，副本排除 .git、環境變數檔、憑證與 node_modules。本機 Qwen 為補充審查。

120頁整合與4模型稽核已完成，33項意見均經主 agent 逐項驗證或排除；修正及完整測試見 [多模型稽核紀錄](../2026-09-12-multi-llm-audit/README.md)。正式發布結果以該目錄 release.json 為準。
