## Method

All 21 current Wikimedia Commons description pages were reopened. The audit used the current description page and MediaWiki API `action=query`, `prop=revisions|imageinfo`, `rvprop=ids|timestamp|content`, and `iiprop=extmetadata|metadata|commonmetadata|url`. Linked Flickr pages or Flickr oEmbed metadata were used only to distinguish a supplied 2.0 work title where the Commons source field pointed to that original. No photo, thumbnail, article body, transcript, video, or audio was downloaded during this review.

The audit did not promote a filename-derived MediaWiki `ObjectName`, a narrative description, generic Commons footer, Creative Commons boilerplate, or automated Flickr-review template into a work title or licensor notice. Unknown title/notice facts remain explicit `null` values in the registry. Every row is bound to the exact Commons `oldid` revision checked on 2026-08-12.

Dwight Powell and Moritz Wagner are the deliberate `ObjectName` exception: both original files contain the same embedded IPTC `ObjectName` and `ImageDescription`, `Basketball-Länderspiel: Deutschland gegen Kanada`. That supplied embedded title is distinct from the filename-derived MediaWiki page label and is therefore retained for both records.

- Historical `nba-v3` policy files remain byte-identical. New immutable `nba-v4` binds both v3 digests and changes only the player-photo attribution controls; its JSON/Markdown SHA-256 values are `3320fe2051fc091aa055d5cdd8bcdacf24073c3964cac3d1a982666a2aafbf68` and `929ac5f125db222d8eb6e98a3a52b1778ebd28c743884c945ab917619ebd5994`.
- The fail-closed checker freezes both canonical registry digests, rejects any v1→v2 projection drift outside the new rights fields and v4 policy binding, and also rejects source-revision mismatch, missing title state, notice-state inconsistency, license/bucket mismatch, missing or cross-version SA adapter license, and any BY/CC0 adapter license.
- The renderer has distinct CC BY, CC BY-SA, and CC0 branches. The Adapter's License wording is expressly limited to the crop contribution and excludes other page content.
- Visible source and Adapter's License terms links deliberately omit unscoped `rel="license"`. The [WHATWG license link type](https://html.spec.whatwg.org/multipage/links.html#link-type-license) describes the current document's main content, and [Creative Commons' technical marking guidance](https://wiki.creativecommons.org/wiki/Marking_Works_Technical) likewise requires an explicit subject for an included object; the site has no separate stable URI for its CSS crop contribution. Keeping the exact visible terms links without that relation avoids contradicting the explicit “not the surrounding page” boundary.
