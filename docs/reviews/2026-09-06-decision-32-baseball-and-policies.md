# Decision 32 — 棒球擴充與現行網站說明

依使用者「我覺得棒球的影片可以多一些」新增八支棒球影片，棒球 7 → 15，全站 70 → 78（7 病例、71 動作觀察），維持 14 運動與 7 部位。追加指示要求重新評估頁尾及政策說明，已一併改寫。

## 收錄與來源

Schwarber、Harper 2017、Fowler、Eaton、Bassitt、Cobb、Stanton 2014、Morton 2021。七筆確認日期差為 198、45、241、37、38、175、152 天；Eaton 最早小聯盟熱身賽日期無法確認，returnDate:null，僅描述已確認的 2018-03-17 春訓里程碑。Cobb 2013-07-23 首場復健賽只投兩球就因水泡退場，仍早於大聯盟回歸。Schwarber 採秋季聯盟，Stanton／Morton 採春訓而非例行賽。

實際使用外部 Codex 與 Grok 分別研究跑壘守備及投球打擊，之後獨立 Pass 2 逐篇閱讀來源，另重算日期與驗證綁定。Codex 初次設定 gpt-6-astra 因 CLI 版本不相容失敗，保留紀錄，改用 gpt-5.5 成功；Grok 300.861 秒、exit 0。AGY／Qwen 本批未執行。Eaton 是後續替代稿，經獨立原文 Pass 2 驗證，未宣稱原 Codex 已查核該例。

模型的 Morton 鋼板與春訓場次宣稱未採用，Cobb 局數誤差未進入文章。Jeter 原 MLBGlobal12 影片禁止站外播放，另一官方片段屬 2013 年其他比賽，八秒候選只是外連文字卡；三者均排除。測了 11 個不同影片 ID、12 次原生 iframe 探測，不能把播放器可播放等同內容符合。

八支選片皆已在自有 HTTPS origin 原生 iframe 實播，並逐段檢視動作。此為候選探測，不冒充新增網站路徑的實播；預覽／正式實際頁面另行驗證。Morton 從 24 秒開始，其他七支從開頭播放。封面八張採 YouTube 預設縮圖，保存來源與雜湊。原病例、醫療核准及過往影片資料未改。

## 頁尾與政策

頁尾導覽改為「影片來源與資料查核」「影片與圖片使用說明」「隱私與播放設定」及「認識影片圖鑑」。刪除以 NBA 為中心和歷史照片為主的舊摘要；內容按目前跨運動影片、實際出賽、未知日期、AI 輔助但原文複核等現況重寫。工程 digest 與舊內部審查術語不再出現在民眾說明。

隱私說明依實作與 YouTube／Google／Cloudflare 官方文件：本站本地封面與字型、點選後才載入 YouTube、瀏覽器偏好、無本站廣告或訪客分析程式；隱私加強模式不宣稱零資料處理，外部主站表單適用主站政策。主站聯絡／隱私網址已 HTTP 200 核對。

影片可內嵌不代表持有影片著作權或可再次轉用；縮圖不一定是受傷瞬間或第一個畫格。提供來源更正及權利問題入口。歷史照片逐檔署名與原醫療提醒文字完整保留。獨立複核抓到「一般衛教皆經醫師審閱」範圍過廣，已改為公開來源整理，避免將歷史指南核准擴大解讀為所有新增內容簽核。

官方參考：[YouTube 內嵌與隱私加強模式](https://support.google.com/youtube/answer/171780?hl=zh-Hant)、[Google 隱私政策](https://policies.google.com/privacy?hl=zh-TW)、[Cloudflare 隱私政策](https://www.cloudflare.com/privacypolicy/)。
